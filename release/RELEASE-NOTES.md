# Khidmat 2.0.0

[Download Khidmat for Android](https://github.com/tatheer583/Khidmat-App/releases/download/v2.0.0/khidmat-universal.apk)

Open the link in your phone’s browser. After the download finishes, open Files → Downloads → khidmat-universal.apk, then Install → Open. Allow installation from your browser if Android asks.

This version opens without a backend connection or account setup. Supabase and the server database code have been removed.

- Create a Worker or Work giver profile with profession, experience and details.
- Save actual worker contacts, search in English/Urdu/Roman Urdu, and mark favorites.
- Call, open SMS and share a request using your phone’s apps.
- Save appointments with time, address, price, notes and progress.
- Switch between English and Urdu, including right-to-left layouts.
- Export and restore a validated phone backup.

Records stay on the phone. An appointment’s status does not notify another person. Shared worker discovery, OTP login, live chat and cross-phone updates require an online service and are absent in this version.

Android 7.0 or newer. One universal APK supports ARM64, ARM32 and x86-64. Build 5003 retains the Khidmat release signer for updates. Back up local records before uninstalling or clearing app storage.

The iOS source is included. An installable iPhone release still requires Apple signing and TestFlight/App Store distribution.
